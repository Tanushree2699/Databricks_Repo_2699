# Databricks Retail Project 
Designed and implemented an AWS and Databricks-based data platform where S3 file arrivals triggered AWS Lambda to orchestrate Databricks jobs for near real-time ingestion. 
Built automated data quality validation, duplicate detection, schema enforcement, and SCD Type 2 processing to load data across Raw, Lake, Hub, and Mart layers, supporting reliable business reporting through scheduled downstream transformations.
